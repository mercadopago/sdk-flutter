# MercadoPago SDK for Flutter

Official Flutter SDK for integrating MercadoPago payments into mobile applications.

## Features

- Card tokenization (new and saved cards)
- Payment method detection by BIN
- Installment calculation
- PCI-compliant card input fields
- Complete hosted checkout UI
- Device fingerprinting for fraud prevention

## Requirements

- Flutter 3.x+
- Dart 3.x+
- iOS 13.0+
- Android API 23+
